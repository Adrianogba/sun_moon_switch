# sun_moon_switch_example

The demo app for [`sun_moon_switch`](../). It shows the switch at every size
preset, three color palettes, and the calm, snappy and disabled states, over a
background that follows the toggle.

```bash
flutter run
```

Only web is configured here. Run `flutter create --platforms=<os> .` first if
you want to try it on a device or on desktop.

`tool/shoot_test.dart` renders this page to `../screenshots/` for the README.
